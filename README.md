# 🎁 A surprise for Cristal

A small, hand-made website. Open `index.html` — that's all.

## What's inside

| File | What it is |
|---|---|
| `index.html` | The whole site — everything is baked in, nothing to install |
| `sunny-days.mp3` | The song |
| `images/1.jpg`, `2.jpg`, `3.jpg` | The photos |
| `.nojekyll` | Makes GitHub Pages serve the files exactly as they are |

## Notes

- Everything is plain HTML/CSS/JS in **one file** — no frameworks, no build step, no internet needed.
- The lyrics are word-by-word synchronised to the song.
- Best with sound on. Headphones recommended. 💗
